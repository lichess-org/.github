Lichess is a charity and a free, libre, no-ads, open source chess server.

* [Complete list of source repositories](https://lichess.org/source) (most, but not all, can be found below)
* [About](https://lichess.org/about)
* [Discord](https://discord.gg/lichess)
* [Development Onboarding](https://github.com/lichess-org/lila/wiki/Lichess-Development-Onboarding)

Actively maintained projects not yet listed on the [source page](https://lichess.org/source):

* [berserk](https://github.com/lichess-org/berserk) — Python client for the Lichess API
* [broadcaster](https://github.com/lichess-org/broadcaster) — Broadcast your chess games on Lichess
* [dart-lc0](https://github.com/lichess-org/dart-lc0) — Leela Chess Zero (lc0) bindings for the mobile app
